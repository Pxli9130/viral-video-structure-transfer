You are the senior engineer for this repo. Implement Spec v4.1 as an addendum to Spec v4.0.

Goal:
Add provider-aware AIGC/audio routing without breaking the core evidence-faithful structure-transfer system.

Core principles:
1. Seedance 2.0 is an optional AIGC video-fill provider, not a core dependency.
2. Seedream 4.0 is an optional image/poster/background fill provider.
3. ElevenLabs is the optional audio intelligence stack: Scribe, TTS, SFX, Music, Audio Isolation, Dubbing/Lip Sync.
4. Remotion + FFmpeg remain the deterministic rendering backbone.
5. No sample frame/audio may be sent to AIGC providers unless explicitly authorized.
6. All generated assets must include provenance.
7. Every optional provider must have a deterministic fallback.
